En este laboratorio trabajé en un prototipo de escritorio cuyo objetivo es saludar al usuario de manera personalizada. La aplicación solicita el nombre, la edad y la hora con la selección AM o PM, y luego presenta un mensaje que incluye el nombre y la edad ingresados.

Para organizar el proyecto utilicé Java y JavaFX para construir la interfaz gráfica, y Maven para configurar las dependencias y facilitar la ejecución. Separar los campos de entrada, el botón y el mensaje de resultado permite que el flujo de uso sea sencillo de entender.

Una parte importante del desarrollo fue considerar la validación de los datos. No basta con mostrar un saludo: también hay que revisar que los campos estén completos, que la edad sea un número entero dentro de un rango razonable y que la hora tenga un formato válido. Esto evita que la aplicación procese entradas incorrectas sin avisar al usuario.

El trabajo también me permitió relacionar los requisitos del enunciado con los componentes de una interfaz y con las acciones que ocurren cuando se presiona un botón. La documentación del proyecto es importante porque explica qué se necesita instalar y cómo ejecutar la aplicación desde otra computadora.
